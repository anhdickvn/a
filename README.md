# Minecraft FIXED UI v46

v46 fixes three reported issues from v45:

1. Chat component links such as “Đăng nhập”, “Đăng ký”, “Đổi mật khẩu” keep their Minecraft colors, are underlined, and remain clickable even when § color codes appear inside the same component.
2. The entire “Display lore / Left click / Right click / Drop all” row is now tappable, not just the SF Symbol icon.
3. Hover items in chat are explicitly link-enabled and underlined so tapping the item text opens the tooltip. WASD/SPACE movement uses one short finite pulse without a background movement loop.

Build target remains compatible with the existing iOS 16 source level.
